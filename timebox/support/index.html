Support

Need help with TimeBox? We're here to help.

If you're having trouble with TimeBox, have a question about how something works, or want to report an issue, contact us and we'll do our best to help. TimeBox is a native macOS app, and support is handled directly by TotalFlux.

Get in touch

For questions, troubleshooting, feedback, or help with TimeBox, email us at:

totalflux-help@yahoo.com

When contacting support

To help us resolve an issue more quickly, please include as much relevant information as possible, such as:

  • A brief description of the issue
  • What you expected to happen
  • What happened instead
  • Your macOS version
  • Your TimeBox version
  • Any steps that reliably reproduce the issue

Before contacting support

Make sure you're running the latest version

If TimeBox is behaving unexpectedly, first make sure you're running the latest version available from the Mac App Store.

Restart TimeBox

If a feature appears unresponsive, quitting and reopening TimeBox may resolve temporary issues.

Still need help?

If the issue persists, contact us at totalflux-help@yahoo.com and include the details above.
